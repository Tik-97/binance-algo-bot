SANDBOX WALLET SIMULATION
========================

This is a standalone entertainment / exploratory wallet simulation.
It is NOT part of the main reverse-analysis research conclusions.
It is NOT proof that the proxy is safely tradable.
It uses an approximate liquidation model, not exact exchange liquidation math.
The purpose is to compare how wallet behavior changes under different aggressiveness assumptions.

Source used: current practical Cluster 1 short model-signal set from `eth_cluster1_short_model_signals.csv`. This file is already a Stage A-style signal source, so no extra stage filter was applied.
Candles used: `ETHUSDT_1m.csv`.
Stage request: `A`.
Output folder: `C:\Users\Tigran\Desktop\Binance\fun_backtests\sandbox_wallet_multi_risk`.

Core assumptions:
- Starting balance: $400.00
- Leverage: 10.0x
- One trade at a time: True
- Fee per side: 0.040%
- Slippage per side: 0.025%
- Liquidation approximation buffer: 0.50% underlying move below the simple 100/leverage threshold
- Entry hours filter: 13:00 to 17:00 UTC
- Breakeven protection enabled: True
- Breakeven trigger: +0.20% favorable underlying move from entry
- Ambiguous candles are resolved adverse-first for safety: liquidation > protective stop > take-profit.
- Liquidation approximation assumes the allocated trade margin is lost; with smaller margin fractions the rest of the wallet survives.
- After the breakeven trigger, the active protective stop is moved to a near-entry break-even level.

Risk modes:
- full_margin: 100% of wallet used as margin per trade
- half_margin: 50% of wallet used as margin per trade
- quarter_margin: 25% of wallet used as margin per trade
- tenth_margin: 10% of wallet used as margin per trade
